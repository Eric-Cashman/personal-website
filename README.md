# Personal Portfolio Website

 Professional Website to showcase my projects, and skills.

## Tech Stack
Framework: React with Vite

Language: TypeScript

Styling: Tailwind CSS

Animations: tsParticles (Firefly configuration)

UI Design: Custom responsive layouts, modular components

## Key Features
Dark Minimalist Aesthetic: Deep slate/midnight background (#1a1a24) accented with vibrant teal (#64ffda) highlights.

Interactive Background: A subtle, ambient particle (firefly) effect running on a fixed background layer (z-0) that never interferes with text readability or element clicks.

Smart Navigation: Fixed dark header with hide-on-scroll behavior and smooth section linking.

Modular Sections: * Hero: Clean introduction with a direct call-to-action button for your resume.

About: Background and personal journey into software development.

Experience: Split-column career and work-study timeline.

Projects: Featured project card layout with image preview support and tag-based tech stacks.

Fully Responsive: Optimized for both desktop and mobile viewports.

## Getting Started
Prerequisites
Make sure you have Node.js installed on your machine.

Installation & Setup
Clone the repository:

Bash
git clone https://github.com/Eric-Cashman/personal-website.git
Navigate into the directory:

Bash
cd personal-website
Install dependencies:

Bash
npm install
Run the development server:

Bash
npm run dev
View locally: Open your browser and navigate to http://localhost:5173.
